# Security policy

## Reporting a vulnerability

Report vulnerabilities privately: open the repository's [Security tab](https://github.com/AlanWYChen/Stampede/security) and choose **Report a vulnerability**. This uses GitHub's private vulnerability reporting, so the report isn't public.

Do not open a public issue or pull request for a vulnerability. Use sample data rather than real clipboard contents in reports and reproduction steps.

## Scope

- Clipboard capture and monitoring
- History storage and encryption
- Keychain key handling
- The build and install scripts in `scripts/`

## Supported versions

Stampede ships as source and has no releases. Only the latest `main` branch is supported, so check that the issue still reproduces there before reporting.
